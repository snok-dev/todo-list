# To-Do List

A simple to-do list that runs in your web browser. No installation needed.

## Features

- Add tasks
- Tick tasks off when they're done
- Delete tasks
- Show all tasks, only unfinished ones, or only finished ones
- Clear all finished tasks at once
- Your tasks are saved in your browser, so they're still there after you close the page

## How to run

Download the project and double-click `index.html`. It opens in your browser.

## How it's built

- `index.html` - the structure of the page (what's on it)
- `style.css` - how it looks (colours, sizes, spacing)
- `script.js` - how it behaves (adding, ticking off and deleting tasks)
